# SiLapang - Sistem Reservasi Lapangan Olahraga (v3)
Aplikasi berbasis Java PBO dengan arsitektur berlapis (`model`, `payment`, `repository`, `service`, `ui`).

## Cara Menjalankan Program
1. Buka proyek `SiLapang` di Apache NetBeans.
2. **Menjalankan Aplikasi Utama:** Buka file `src/App.java`, lalu tekan **Shift + F6** (*Run File*).
3. **Menjalankan Pengujian Unit:** Buka file `src/service/ReservasiServiceTest.java`, lalu tekan **Shift + F6** (*Run File*).
